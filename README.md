# Sliker.io

A neon slither-style snake game for the browser. Eat food to grow, grab power-ups, and outlast the AI snakes on the leaderboard.

**Play it:** https://reihanhs.github.io/slither-reihan/

## Controls

- Move the mouse to steer.
- Hold the mouse button to boost.

Mouse only for now; there are no touch controls.

## Run locally

```bash
npm install
npm run dev      # Vite dev server
npm run build    # type-check + production build into dist/
```

Built with TypeScript and Vite, drawn on an HTML5 canvas.
